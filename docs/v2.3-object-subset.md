# v2.3 Supported Object Subset (Core Page/Note)

This document records the Anytype object synchronization features supported
in the v2.3 milestone. Features outside this subset were deferred.

## 1. Supported Object Types

| Object Type | Protobuf Enum | Description |
|-------------|---------------|-------------|
| **Page** | `SmartBlockType.Page` | Standard Anytype Page with basic text blocks. |
| **Note** | `SmartBlockType.Note` | Standard Anytype Note (similar to Page but with simplified UI). |

## 2. Supported Block Semantics

The following block types from `any_block/models.proto` and `any_block/changes.proto` are considered in-scope:

- **Text Block:** Basic markdown-like text content.
- **Header Blocks:** H1, H2, H3.
- **List Blocks:** Bulleted and numbered lists.
- **Checklist Blocks:** Basic checkbox lists.

## 3. Supported Attributes/Metadata

- **Title:** The primary name of the object.
- **Creation/Modification Date:** Basic timestamp tracking.
- **Icon/Emoji:** Simple object icons (stored as string/emoji).

## 4. Deferred / Out-of-Scope (v2.3)

The following areas are **not** supported for v2.3 interop:

- **Sets & Collections:** Complex object relationships and view queries.
- **Templates:** Object instantiation from predefined layouts.
- **Advanced Blocks:** Table, File/Image (though file *blobs* are in v2.2, *embedding* them in objects is deferred), LaTeX, Code, etc.
- **Deletion:** Complete object deletion (tombstoning).
- **Permissions:** Per-object ACL overrides (v2.3 assumes space-level ACL only).
- **Relations:** Custom properties and non-standard attributes.

## 5. Compatibility reference

Interoperability is verified against the `ObjectSyncStream` behavior of the official `any-sync-node` (v0.9.x+) using the captured `test_vectors/phase27-object-truth.json` artifact.
